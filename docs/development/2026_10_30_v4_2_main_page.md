# Version 4.2.0: main-page changes requested by Igor Shuryak (2026-10-30)

## Requests (verbatim intent)
1. List only regimens that reduce the standard by at least 5 fractions.
2. Sort with more fractions at the top.
3. Hide "Tumor condition holds in", "Refit support" and "Notes" by default behind a "details" control; fewer columns allow a bigger font.
4. Add early and late toxicity BED change columns next to the tumor BED change.
5. Add a plot at the bottom: x = number of fractions, y = BED difference from the standard; blue tumor, red early, green late.
6. Archive the pre-v4 shinyapps.io sites so only v4 is live.

## Choices made (not specified in the request)
- "At least 5 fewer fractions" is applied as a search ceiling (`V4_GRID$m_range = 5:30`, constant `v4_min_fewer_fractions`), so the empty-list message and the tests use the same range. Easy to reverse.
- Details control: a checkbox above the table. The Refit support and Notes footnotes are hidden with their columns; the two-model footnote stays because the DI / DD column is always shown.
- Each row covers a range of doses, so the plot draws one bar per endpoint spanning the listed doses (min to max), not one point. Tumor is shown under both models (dark blue DI, light blue DD) because the list admits a row when either model meets the condition. Dashed lines mark the −5 Gy tumor and +5 Gy toxicity limits. The x axis runs 30 → 16 to match the table order.
- Early-toxicity red is `#D62728` (the colorblind-safe vermilion read as orange).
- `v4_signed_range()` now prints "+0.0" instead of "−0.0" for values that round to zero (first visible in the new late column at 27 fractions).

## 4.2.1 (same day): range explanation under Details
Igor asked how a range such as "BED DI −1 to +1" is determined and that it be explained in the Details view. Added a paragraph (shown only with Details ticked) plus a live worked example for the top row, built by `v4_range_example()`: it names the doses kept and, for the next 0.05 Gy step below and above, which conditions fail (`v4_failed_conditions()`). At the defaults: 30 fractions keep 2.10–2.25 Gy; 2.05 Gy fails the tumor condition, 2.30 Gy fails the early and late limits; DI change −3.2 to +3.3 Gy₁₀, matching a hand calculation from the DI formula.
