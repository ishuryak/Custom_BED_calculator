# Custom_BED_calculator

You can try the current calculator [here](https://ishuryak.shinyapps.io/custom_bed_calculator_v3/). The code is on the [v3 branch](https://github.com/ishuryak/Custom_BED_calculator/tree/v3), with updates on the [fixes branch](https://github.com/ishuryak/Custom_BED_calculator/tree/fixes_v32_review_2026_10_26). If you're comparing the code with the website, check Model and sources, then Version, to see which revision is running. The branches may have changes that aren't live yet.

**Version 2:** use the [live v2 calculator](https://ishuryak.shinyapps.io/custom_bed_calculator_v2/) or its [source branch](https://github.com/ishuryak/Custom_BED_calculator/tree/v2-toxicity-hypofractionation). This `main` branch contains version 1, whose DD calibration is incorrect when tumor α/β differs from 10 Gy.
Custom BED versions for HNSCC using dose-independent (DI) and dose-dependent (DD) repopulation models
