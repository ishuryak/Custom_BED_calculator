Version 3 source is on the [v3 branch](https://github.com/ishuryak/Custom_BED_calculator/tree/v3), with pending fixes on [fixes_v32_review_2026_10_26](https://github.com/ishuryak/Custom_BED_calculator/tree/fixes_v32_review_2026_10_26). **Version 2:** use the [live v2 calculator](https://ishuryak.shinyapps.io/custom_bed_calculator_v2/) or its [source branch](https://github.com/ishuryak/Custom_BED_calculator/tree/v2-toxicity-hypofractionation).
